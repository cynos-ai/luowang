2. **一次交付截图采集及标签链路**：修改固定 Playwright 补丁，将非空字段拒绝改为警告，检测异常为 unknown；实际截图失败保留。由既有采集/Evidence Store owner 绑定图片文件、哈希和检测标签，贯通文件列表、图片读取及报告引用，正常上传与自动归档保持。不先单独取消拒绝而遗漏标签。更新补丁版本形状/幂等回归，不升级依赖。
3. **补齐填写输入保护与反例**：检查固定 adapter 的 fill_form/type 结构，复用运行时敏感值登记，在实际填写前记录必要值；两入口一致，失败不静默绕过。添加未预登记的随机合成输入及“否认句复述值”回归；明确 writer 前模型行为与 writer 后保护的不同判定，原反例不能改为 pass。
4. **零模型联合验收**：真实 MCP 页面覆盖非空字段、空字段、检测异常、截图失败、明文回显、清空会改变错误状态、frame/开放 Shadow DOM。每例比较截图前后状态和像素，不能让测试脚本通过清空现场制造成功；同时检查 Run 隔离、标签完整性、图片字节上传与自动归档，运行完整 quality/local acceptance。
5. **候选与模型复验**：固定包含新依赖补丁和应用代码的完整 runtime，不能只覆盖 dist。先原生预检，再冻结新输入/预算/停止条件；验证模型确实不修改现场、原图可审核、文字如实且脱敏。只跑新候选新案例，不重写或重跑历史轮追分，失败停止。
6. **回到整体收尾**：将新证明回填旧 change 的 AC-FOLLOWUP-04，继续正常业务四 Session 与剩余验收、独立人工评分。标签不改变已成立的功能结论，三个 Issue 和 PR 发布状态依据完整证据决定，不自动关闭或合并。
