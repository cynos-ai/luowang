# 模型设置交互收尾 Intent

- 日期：2026-10-04
- 状态：已确认

## 问题

模型与角色页面把 Thinking 作为不可编辑的说明展示，Main 与 Final Main 又显示成不同阶段策略，无法表达操作者已保存的角色偏好。原生 datalist、分散的模型能力文字、整行目录状态和输入框外的 Secret 状态也造成版面松散、控件风格不一致。右上角管理员入口看起来像普通操作按钮。

## 期望结果

- 模型变化时按角色给出安全默认 Thinking，同时允许操作者从模型实际支持的档位中选择并保存。
- Main 与 Final Main 共用 Main 的模型和 Thinking 配置。
- Provider、模型、模型能力、Secret 和管理员入口使用一致、紧凑、可访问的交互。
- 运行时和连接检查尊重有效的已保存 Thinking；旧配置无效时安全回退。

## 约束

- 不回显 Secret 原值，不改变运行中的配置锁定规则。
- 保留手工输入未收入目录的 Provider 和模型 ID 的能力。
- Reviewer 仍必须使用支持图像输入的模型。
- 不增加新的图标或选择控件依赖。

## 非目标

- 不改变 Provider 目录来源、角色数量或 Session 隔离结构。
- 不迁移或删除历史 Run。
