# 复测问题收敛 Spec

- MCP以当前Node可执行文件启动从Harness自身依赖位置解析的已安装CLI；不从目标仓库或证据目录解析依赖，不使用npx在线下载回退。证据目录仍为cwd，headless/isolated与禁用任意代码工具边界保持。
- 单份权威交接不限制所属Session重写同一工件。Main发现判断变化或patch失败后必须纠正计划中的失实描述；Reviewer结合实际patch状态审核维护声明，不另起Session或增加语义正则。
- 原样复用工具返回的证据地址；没有地址时只引用已知证据ID，不构造URL。程序地址校验是否需要增加，先检查已有owner和边界，再实施，不用新的语义门禁替代审核。
- 验收区分：工程回归、断网MCP真实启动/截图、Qwen定向复测、实际部署联合验收。前一层通过不代表后一层通过。只本地提交，不push/merge/release。
