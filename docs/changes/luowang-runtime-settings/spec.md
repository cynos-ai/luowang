# 罗网运行设置 Spec

- 日期：2026-10-05
- 状态：已确认
- [Intent](intent.md) · [Plan](plan.md)

## 行为

- 全局设置新增“系统设置”，包含管理员显示名称、修改密码、任务调度和启动配置。
- 最大并发项目数允许 1–8，默认取 `LUOWANG_MAX_CONCURRENT_PROJECTS` 或 2；首次在线保存后以数据库值为准并跨重启保留。
- 修改并发上限立即影响后续队列认领。同一项目继续串行，正在运行的测试不被停止。
- 密码修改继续要求当前密码，成功后撤销当前会话。
- 监听地址、端口、日志等级和数据路径只读展示，仍由部署环境配置。

## 验收

- 设置页能读取并保存 1–8 的并发上限，越界值由服务端拒绝。
- 保存后调度器和数据库持久值一致。
- 管理员名称与密码可在同一分组管理。
- 工作台和系统状态不展示不可操作的占用/上限数字。
