# 语义判断归属 Intent

## 问题

Harness 用计划中的浏览器/视觉关键词推断执行需求，用“无需场景测试”等措辞当作零场景依据。这会把范围排除当成执行要求、遗漏换一种说法的真实需求，并可能把否定句当成认可。Provider 连通性错误也存在按宽泛消息关键词猜具体原因的问题。

## 期望

业务含义由现有角色结合上下文判断；Harness 负责真实能力、执行事实、权限及格式，不用关键词冒充语义理解。正常 API 不再因提及未覆盖的浏览器能力而被阻塞。

## 约束与非目标

保留 Main/Runner/Reviewer 和原 Session 数、单向交接、确定性清理、Secret/路径/命令/证据安全边界。无需兼容旧协议，不加新判断 Agent 或独立语义分类服务。不修改历史评估，不扩大官网测试范围，不推送或发布。证据链接格式改进不并入本次。
