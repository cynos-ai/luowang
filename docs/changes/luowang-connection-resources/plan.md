## 风险与控制

- 资源复用扩大凭据影响面：运行中引用检查与删除引用约束必须由服务端强制执行。
- 旧项目已有加密 Token：保留项目 Secret 回退，不做无法验证的密文搬迁。
- 服务器配置容易被误认为已支持远程执行：API 和页面返回明确能力状态，本批次不接入执行路径。
- 新迁移改变正式数据库：使用离线备份升级，保持幂等并核验外键。
