# 命名连接资源 Spec

- 日期：2026-10-05
- 状态：已确认
- [Intent](intent.md) · [Plan](plan.md)

## 1 GitHub Token

- Token 资源包含稳定 ID、唯一显示名称、是否已配置、创建时间和更新时间；明文只加密保存。
- 新建项目可选择“不使用 Token”或已有命名 Token；下拉框旁提供“新增”入口并跳转到统一的 GitHub 设置页。
- 项目绑定已有 Token 时，仓库核验和后续 GitHub 操作读取同一个资源值，不复制明文到项目 Secret。
- 项目设置可更换或解除 Token 绑定；旧的项目专属 Token 在没有命名绑定时继续作为兼容回退。
- 被项目引用的 Token 不能删除；轮换 Token 时所有绑定项目继续引用同一资源。

## 2 执行服务器

- 服务器资源包含稳定 ID、唯一显示名称、主机、SSH 端口、用户和认证方式。
- 认证方式为密码或 SSH 私钥。密码、私钥和可选私钥口令只进入 Secret Store；列表只展示配置状态。
- 项目可绑定一个服务器；未绑定时显示并保存为“罗网本机”。
- 被项目引用的服务器不能删除。服务器变化使绑定项目的运行准备快照失效。
- 本批次不通过服务器资源执行远程命令；界面明确标识远程执行尚未启用，避免把“已配置”冒充“已可执行”。

## 3 页面与反馈

- 全局设置新增独立的“GitHub”和“执行服务器”分组，分别支持新增、编辑、轮换和删除，避免两类资源共用过长页面。
- 新项目接入页在仓库信息中提供 Token 和执行服务器选择；两个选择器旁分别提供“新增”入口并跳转到对应设置页。
- 项目设置的“凭据”分组管理 Token 绑定；“执行环境”分组管理服务器绑定。
- 所有保存、轮换和删除操作使用共享 Message；删除使用站内确认弹窗；枚举选择使用共享 SelectBox。

## 4 项目运行文件

- 项目可登记多个受控文件，每项只包含项目内相对路径和加密内容；机制不识别或限制扩展名，可用于 `.env`、`.env.test`、`config.yml`、`config/beta.json`、文本证书等不进入 Git 的文件。
- 路径禁止绝对路径、反斜杠、空段、`.`、`..` 和控制字符；同一项目内路径唯一，单文件最大 256 KiB。
- 页面和接口只返回路径、配置状态和更新时间，不回显内容。项目有待处理请求时不能更新或删除。
- 本批次先完成安全保管和项目归属；在命令输出脱敏与临时工作区清理完成前，不把文件注入 Run，页面不得暗示已生效。

## 5 安全与并发

- 资源名称不包含 Secret，大小和字符集受限；服务器主机不得包含 URL 凭据、路径或控制字符。
- 项目存在 queued、running 或 waiting_archive 请求时，不允许改变其 Token 或服务器绑定。
- 轮换被运行中项目引用的 Token 或服务器认证 Secret 时拒绝操作。
- API 返回资源元数据和绑定 ID，不返回 Token、密码、私钥或口令。

## 6 验收条件

- AC-CR-01：可创建命名 Token，新项目可使用已有 Token 完成仓库核验且不复制明文。
- AC-CR-02：项目运行时 GitHub 操作读取绑定 Token；未绑定时兼容旧项目专属 Token。
- AC-CR-03：可配置密码或私钥服务器，并在项目中绑定或选择罗网本机。
- AC-CR-04：被引用资源不可删除，运行中项目不可切换绑定或轮换相关 Secret。
- AC-CR-05：接口、日志和页面不回显 Secret；状态变化均有 Message，危险删除均有站内确认。
- AC-CR-06：数据库升级可备份、幂等执行并通过外键与完整性检查。
- AC-CR-07：项目可保存、轮换和删除相对路径配置文件，内容不回显且当前不冒充已注入 Run。
