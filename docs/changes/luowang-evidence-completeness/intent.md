# 证据盲区与记录精度 Intent

- 状态：需求基线；仅编写 intent，spec/plan 待与 #71 的边界确认后编写
- 关联：#64、#65、#68、[run-evidence-followup](../luowang-run-evidence-followup/intent.md)、[screenshot-capture-integrity](../luowang-screenshot-capture-integrity/intent.md)

## 问题

### A 族：工具层回避（与已修正的截图护栏同源，3 项）

1. **fill_form 内容省略**：浏览器填写操作只保留时间回执，不记录实际填写的值。若填错字段或填了不该填的内容，执行记录无法复原"实际提交了什么"，审核缺少关键材料。
2. **自动导航快照正文排除**：导航产生的快照仅保留文件链接与操作时序，正文不作为内容证据；若缺陷只体现在该正文，信息丢失。文件本体是否留存可查，未见写明。
3. **证据类别手工维护**：Reviewer 可读类别（command/browser/image）为手工清单。新增证据工具（如 #68 的 Cookie 重放）默认不可读，直到人工补类别。#68 已实际发生一次；清单靠人脑维护，同类问题会重演。

### B 族：模型记录精度（已知未修，3 项）

4. **来源归因失实**：把自身观察表述为他人交付（如"Runner 报告识别了 X"而 Runner 未述及）；已有多次实际观察。
5. **时钟原点缺失**：以文件名时间加相对偏移直接当作已确认的事件时间，未建立时钟基准。
6. **计数口径不一致**：口头汇总与正文明细条数不匹配（如"4 项确认 + 1 项未验证"但表格仅列 4 项），且不解释口径。

## 期望结果

### A 族（工具层；修法为登记/映射，不省略不回避）

1. fill_form 填写的值按控件结构登记为运行时敏感值；操作记录保留字段与脱敏后内容，不省略正文。
2. 导航快照明确处置：或正文经同源登记脱敏后可读，或如实标注"正文留存于何处、如何访问"；不留无归属暗角。
3. 新增防呆：证据工具产生记录而无类别映射时，**预检直接报错**，不再静默不可读。

### B 族（模型行为；修法为指令 + 定向验证）

4. 自身观察与引用分开：观察明确归属；引用他人交付必须以其原文为据。"模型观察被误写为 Runner 报告"保留为反向测试用例。
5. 时间表述区分"记录时间"与"事件时间"；无时钟基准时不得使用"确证事件时间"类措辞。
6. 汇总数、明细表、口径三者一致；不一致时以明细为准并说明差异。
