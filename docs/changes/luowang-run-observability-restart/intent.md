# Run 可观测事实重启持久化 Intent

## 当前问题

发布前重新启动候选实例后，历史 Run API 仍能返回报告、Bug 和归档状态，但截图 Evidence、阻塞原因、场景进度与活动只存在于原进程内存。进程重启后网页无法完整展示这些事实，真实 live 验收也不能复核历史截图。

## 期望结果

完成 Run 时把网页与验收需要的可观测事实持久化到 SQLite；服务重启后 `/api/runs/:runId` 返回与完成时一致的 Evidence、阻塞原因、场景进度和活动。

## 约束

- 不把 Secret、模型思考或原始会话写入数据库。
- 不改变 Git 报告作为长期正式结论的职责。
- 旧 Run 无法凭空恢复的字段保持为空，不伪造历史事实。
- 数据库迁移必须兼容现有 v0.2.1 数据卷。

## 非目标

- 不持久化每次工具调用或完整执行日志。
- 不为旧 Run 从 OSS 或报告文本猜测并回填元数据。
