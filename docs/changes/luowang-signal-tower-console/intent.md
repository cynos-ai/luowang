# 信号控制塔控制台视觉改版 Intent

- 状态：设计方向已选定，生产实现和发布版本尚未确认。
- 决策：以「信号控制塔」为控制台视觉与信息架构，主配色选「海图蓝」；吸收「系统图谱」的背景网格、边缘刻度和指标节点，而不是另做图谱产品。
- 设计参照：[可交互原型](../../../prototypes/luowang-signal-control-tower.html)；原型仅供比较，不是产品代码或验收结果。

## 问题与期望

现有控制台已有 Git、场景、Run、当前执行、配置等真实功能，但页面以同类面板和指标堆叠为主。普通空闲时，首页需要先回答最近测了什么、哪些内容待处理、最近发生了什么，再决定是否发起测试；执行中的逐步细节不应挤进首页。

目标是在保留现有 API 和真实状态语义的前提下，建立高密度、清晰分层的控制台：海图蓝承担工作背景与品牌识别，冰青标记主要操作和聚焦位置；轻量网格提供工程图式定位感，不能妨碍长时间阅读。

## 影响与边界

- 影响登录后的总览、当前测试、Runs、场景、Git、配置及共享导航、状态组件；登录与错误/空状态应视觉一致。
- 数据仍来自现有服务端事实。`blocked`、`interrupted`、归档失败、陈旧缓存、未配置和检查未执行必须分别显示，不能因为换色或排版合并成成功状态。
- 项目/部署/账号边界及项目接入流程若按 [多项目规格](../luowang-multi-project/spec.md) 实现，视觉层须随之适配；本需求不重新定义其身份、Secret、队列、认证或 API 规则。
- 演示原型的 Run ID、健康状态和时间均为合成示例；不进入真实控制台，不作为生产质量证明。

## 非目标与待确认

不借视觉改版新增真实测试能力、多项目逻辑、发布门禁或品牌 Logo；不把原型的浏览器本地模拟操作接入真实 API。

当前 `v0.6.1` 已规划多项目及其 UI，但未纳入本视觉改版。建议在多项目 UI 阶段一并落地以减少二次布局改造；**是否将生产样式改版纳入 v0.6.1 仍需负责人确认**。设计规格与原型可以先独立审阅，不等于已发布或已完成产品改版。
