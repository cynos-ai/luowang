# 信号控制塔控制台视觉改版 Spec

- 状态：选定设计规格；仅原型已实现，生产控制台尚未改版。
- 输入：[intent](intent.md)、[交互原型](../../../prototypes/luowang-signal-control-tower.html) 与 [素材/事实说明](../../../prototypes/brand-spec.md)。
- 版本归属：待确认；不得仅凭本文件宣称已纳入 `v0.6.1`。多项目的业务行为以 [多项目 Spec](../luowang-multi-project/spec.md) 为准。

## 1. 视觉系统

固定采用「信号控制塔」的横向顶部导航、状态带、主次分明的信息墙。选定**海图蓝**，不提供生产界面的六色换肤器；原型保留六色按钮以解释选择过程。

| 用途 | 选定值 | 约束 |
| --- | --- | --- |
| 外框/导航背景 | `#102d39` | 不使用纯黑或紫色 |
| 内容底色 | `#1a3c4b` | 作为网格底，不承载密集小字 |
| 实底信息面板 / 浮起面板 | `#234d5e` / `#2b586a` | 面板内的小字不直接压在网格线上 |
| 主要文字 / 次要文字 | `#f0f9f9` / `#c1d9dc` | 层级由字重、位置和文案共同表达 |
| 聚焦/主要操作 | `#8bd9df`，其上文字 `#173b43` | 仅强调选中、主要操作和重要数值；不表示“测试通过” |
| 分隔线 | `#537985` | 明确版面层级，不靠阴影堆卡片 |
| 语义状态 | 成功绿、警告琥珀、失败珊瑚 | 状态必须带文字/图形，不能只靠色相 |

背景为 **28px 细网格 + 112px 主网格**，叠加透明度约 9%/19%；重要信息放在不透明面板中。版面可使用短刻度、角标和指标节点，但它们只是装饰，不表示坐标、实时遥测或有效证据。沿用「罗网 LuoWang」文字标识；没有授权的图形 Logo 不自行创造。不依赖外部字体服务或图片才能呈现核心界面。

## 2. 页面结构与事实层级

- **总览**：默认按空闲设计。主区域呈现当前有无 Run、最近已完成目标、场景分支的新变化；下方分开列待处理、最近活动、最近可信 Run、队列、依赖。运行中增加简要 Run 摘要和详情入口，不在首页逐步展开执行日志。
- **当前测试**：空闲明确提示；执行中才展示固定 target、四个隔离 Session 的实际阶段、场景进度、脱敏活动和已产生工件。尚未产生的证据不得画成完成。
- **Runs**：可筛选结果和进入详情，分别保留测试结论与归档状态；`blocked` 不视为 `passed`，归档重试不篡改结论。
- **场景**：列表、状态、标签与详情清晰分栏；展示固定原文、期望和历史关联，不能把草稿装作批准场景。
- **Git**：区分远端 HEAD、索引 commit、已完成 target 与当前 Run 固定 target；同步异常标陈旧，merge-source 保留明确确认与排队语义。
- **配置**：按部署/项目/账号边界组织；组件内区分“保存成功”“待检查”“检查通过/失败”。Secret 只显示掩码或配置状态。项目名称和仓库身份常显，防止切换项目后误保存；具体接入、暂停和校验语义遵循多项目 Spec。

所有页面都以服务端读模型为准。交互原型中的虚构 Commit、Run、检查结果及“演示请求”绝不迁入正式界面。现有认证和业务 API 不能因 CSS 改版改变副作用、轮询节奏、Secret 边界或 Run 归属。

## 3. 响应式和可用性

桌面保持可扫描的信息密度；窄屏让信息墙按阅读优先级纵向重排，操作按钮与筛选可触达，无整页横向滚动；宽表允许在自身容器内滚动。键盘焦点、导航当前页、错误/成功/陈旧提示、禁用状态必须明确；文字与底色应达到 WCAG AA 常规文字对比度，且缩放到 200% 不丢失核心操作。动态更新不得抢走输入焦点或用动画代替反馈。

## 4. 验收条件

- **AC-ST-01**：正式控制台六页与登录/空状态使用同一海图蓝 token 系统，无六色换肤器；网格只在底层，信息实底可读。
- **AC-ST-02**：空闲首页展示最近结果、待处理和活动；运行中首页只有摘要，步骤、证据和交接留在详情。
- **AC-ST-03**：`passed/failed/blocked/interrupted`、等待归档/归档失败、陈旧/未知/未配置和未检查在文案、颜色与图形上可区分，原有操作与错误路径不退化。
- **AC-ST-04**：项目切换、首次接入、部署/项目/账号设置满足多项目 Spec 的归属、迟到响应和 Secret 要求，不将原型模拟逻辑带入产品。
- **AC-ST-05**：桌面与约 390px 窄屏无整页横向溢出；键盘/缩放及 WCAG AA 文本对比核查通过，六页真实数据、空数据、错误、陈旧状态浏览器回归通过。
