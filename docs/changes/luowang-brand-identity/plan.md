# 罗网品牌标志接入 Plan

## 范围与实施

1. 从最新 `develop` 建立 `feat/brand-identity` 独立工作区。
2. 保存四个网站运行素材和一张设计说明图；新增共享品牌组件，替换多项目及旧单项目入口的标识。
3. 清理旧 Logo 装饰与响应式覆盖，增加浏览器图标声明。
4. 在 Docker `quality` 环境验证格式、Lint、类型、构建和相关 UI 回归，检查不同视口与资源响应；完成后向 `develop` 提交 PR。

## 风险

- 位图在过度放大时无法增加细节，浏览器展示使用适合的尺寸并保持原比例。
- 彩色与黑白图标不是同一几何母版，必须分别引用，不能自动去色替代。
- 当前服务器开发分支与 `develop` 有其他差异；本需求独立交付，不混入未发布功能。

## 完成证明

- 素材与代码接入已完成。
- 五个素材与用户确认的源文件逐一比较 SHA-256，完全一致；网站运行素材总计约 128 KiB，设计说明图约 720 KiB。
- Docker `quality` 镜像中 `format:check`、`lint`、`typecheck`、`build` 通过。构建保留现有主 JS 包超过 500 kB 的提示，无新增依赖。
- `v07-ui-navigation-smoke`、`v07-ui-workflows-smoke`、`phase8-ui-smoke` 均通过。导航回归增加品牌链接可访问名称和图片解码检查，防止图片替换后出现无名称链接或缺图。
- 隔离临时数据库的 `createProjectApp` 实例中，登录、工作台、深链接刷新、键盘焦点、深色 favicon media 和连接失败页通过检查；PNG/ICO 均返回正确类型。后台任务关闭，不连接 Docker Engine、目标仓库或模型。
- 1440/1024/768/720 CSS px 下页面无横向溢出，Logo 完整且无变形；720 px 用于覆盖 1440 px 的 200% 缩放等效布局，不冒充真实浏览器缩放操作。
- 视觉核对修复登录标题白底白字，并收紧登录布局间距；保持其余业务界面。
- 本机证据保存在本次聊天的 `brand-ui-proof/verification.json` 与 `brand-ui-proof/screenshots/`，不将临时截图和完整素材包提交仓库。全量本地验收及生产镜像检查由 PR CI 执行，不属于上述局部验证的完成结论。
