# 项目删除规则

- 项目列表提供「删除」，沿用共享按钮、确认弹窗和全局 Message。确认显示项目名及无法撤销的范围，取消不发删除请求。
- 管理员可通过 `DELETE /api/projects/:projectId` 删除已启用或已暂停的空闲项目；沿用认证和请求来源校验。
- 删除在同一数据库事务中检查并清除项目配置、项目专属 Secret、受控文件内容、绑定、索引、队列终态、历史 Run 和关联缓存。缺少项目返回 404。
- queued/running/waiting_archive 任务、仍会重试的失败/部分归档、活跃 Run 快照、准备中的镜像或未 released 的执行资源阻止删除，返回 409。不能通过删除项目跳过取消、归档或资源回收。
- 共享 GitHub Token、执行服务器及其凭据不变。GitHub 仓库、场景、报告、Issue 和对象存储证据不变；此操作不删除磁盘目录或 Docker 镜像，也不承诺释放磁盘空间。
- 删除后列表和全局项目上下文更新；旧项目链接不可再访问，同一仓库可重新接入为新项目，不继承旧本地配置。
- 正在结束的后台索引不得恢复已删除项目或随后发起自动测试。删除不改写其他项目。

此规格按用户最新要求增加删除功能，覆盖旧 UI/多项目规格中暂不提供项目删除的范围约束。
